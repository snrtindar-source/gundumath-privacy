Kebijakan Privasi

Gundu QR Studio — versi 1.2 · Diperbarui: 30 Oktober 2026
Prinsip utama: semua pemrosesan QR dan kredensial WiFi dilakukan lokal di perangkat Anda. Aplikasi ini tidak memiliki server, tidak mengirim data ke mana pun, dan tidak mengumpulkan data pribadi.

1. Data yang diproses

  • SSID, password/kunci, dan tipe keamanan WiFi — hanya diproses di perangkat untuk membuat atau membaca QR code. Tidak pernah dikirim keluar perangkat.
  • Riwayat QR (opsional) — jika Anda mengaktifkan riwayat, data jaringan disimpan hanya di penyimpanan lokal perangkat (DataStore). Dapat dihapus kapan saja dari menu Pengaturan → Hapus riwayat.
  • Pengaturan (bahasa, tema, preferensi iklan) — disimpan lokal di perangkat.

2. Yang TIDAK kami lakukan

  • Tidak mengirim kredensial WiFi ke server apa pun.
  • Tidak menulis password ke log, crash report, atau analytics.
  • Tidak menyimpan kredensial tanpa persetujuan eksplisit Anda (riwayat harus diaktifkan).
  • Tidak meminta izin lokasi secara permanen — izin lokasi hanya diminta saat Anda menekan "Gunakan jaringan saat ini" (kebutuhan API Android untuk membaca SSID).
  • Tidak meminta izin kamera kecuali Anda membuka pemindai QR.

3. Izin (permissions)

  • Kamera — hanya untuk memindai QR code, hanya saat pemindai dibuka.
  • Lokasi (fine) — hanya saat Anda memilih "Gunakan jaringan saat ini", sesuai persyaratan API Android 8+ untuk membaca SSID. Ditolak? Fitur itu tidak tersedia, sisanya tetap normal.
  • Penyimpanan — untuk menyimpan/membagikan file PNG QR (via MediaStore, tanpa izin tambahan di Android 10+).

4. Iklan (Google Mobile Ads / AdMob)

  • Iklan banner hanya ditampilkan di layar Pengaturan dan Bantuan — tidak pernah saat memindai, saat dialog koneksi, atau di atas QR code.
  • Iklan dapat dimatikan dari Pengaturan → Tampilkan iklan.
  • Google Ads SDK dapat mengumpulkan data perangkat (ID iklan, versi OS) untuk tujuan pengiklanan, sesuai kebijakan privasi Google: policies.google.com/privacy.
  • Aplikasi ini tidak mengirim data WiFi Anda ke Google atau pihak ketiga mana pun.

5. SDK pihak ketiga

  • Google Mobile Ads SDK — menampilkan iklan (lihat di atas).
  • Google ML Kit Barcode Scanning — pemindaian QR on-device, data tidak meninggalkan perangkat.
  • CameraX — akses kamera untuk pemindaian.
  • ZXing Core — pembuatan QR code, sepenuhnya lokal.

6. Anak di bawah umur

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun dan tidak sengaja mengumpulkan data dari mereka.

7. Perubahan & kontak

Perubahan kebijakan akan ditandai dengan tanggal diperbarui di halaman ini. Pertanyaan: snrt_indar@ub.ac.id.

Privacy Policy

Gundu QR Studio — version 1.2 · Updated: October 30, 2026
Core principle: all QR processing and WiFi credentials are handled locally on your device. This app has no server, sends data nowhere, and collects no personal data.

1. Data processed

  • WiFi SSID, password/key, and security type — processed on-device only, to create or read QR codes. Never sent off the device.
  • QR history (optional) — if you enable history, network data is stored only in local device storage (DataStore). You can delete it anytime in Settings → Clear history.
  • Preferences (language, theme, ad settings) — stored locally on the device.

2. What we do NOT do

  • We do not send WiFi credentials to any server.
  • We do not write passwords to logs, crash reports, or analytics.
  • We do not store credentials without your explicit consent (history must be enabled).
  • We do not request location permanently — location is requested only when you tap "Use current network" (required by the Android API to read the SSID).
  • We do not request camera permission unless you open the QR scanner.

3. Permissions

  • Camera — only to scan QR codes, only while the scanner is open.
  • Location (fine) — only when you choose "Use current network", per Android 8+ API requirements to read the SSID. If denied, that feature is unavailable; everything else works normally.
  • Storage — to save/share the QR PNG file (via MediaStore, no extra permission on Android 10+).

4. Ads (Google Mobile Ads / AdMob)

  • Banner ads appear only on the Settings and Help screens — never during scanning, connection dialogs, or over QR codes.
  • Ads can be disabled in Settings → Show ads.
  • The Google Ads SDK may collect device data (ad ID, OS version) for advertising purposes, per Google's privacy policy: policies.google.com/privacy.
  • This app does not send your WiFi data to Google or any third party.

5. Third-party SDKs

  • Google Mobile Ads SDK — displays ads (see above).
  • Google ML Kit Barcode Scanning — on-device QR scanning; data does not leave the device.
  • CameraX — camera access for scanning.
  • ZXing Core — QR code generation, fully local.

6. Children

This app is not directed at children under 13 and does not knowingly collect data from them.

7. Changes & contact
