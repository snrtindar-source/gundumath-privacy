Kebijakan Privasi

Gundu Math — Latihan Matematika Harian Bertahap

Terakhir diperbarui: 29 Oktober 2026

100% Offline

Gundu Math dirancang untuk berfungsi penuh tanpa internet. Aplikasi ini tidak mengumpulkan, menyimpan, atau mengirim data pribadi anak ke server mana pun. Seluruh data (nama pendek, kelas, progres latihan, riwayat soal) hanya tersimpan di perangkat Anda sendiri.

Data yang Kami Kumpulkan

Tidak ada data pribadi yang dikirim ke server. Gundu Math tidak memiliki akun, tidak terhubung ke internet untuk fungsi utamanya, dan tidak menggunakan pelacak (analytics/tracking).

  • Nickname pendek — hanya nama pendek yang Anda pilih saat onboarding, disimpan lokal di perangkat.
  • Progres latihan — statistik soal, akurasi, dan riwayat, hanya di perangkat.

Iklan & Pelacakan

Tidak ada. Gundu Math tidak menampilkan iklan dan tidak menggunakan SDK pelacakan pihak ketiga.

Keamanan

Karena semua data tersimpan lokal di perangkat, tidak ada risiko kebocoran data melalui server. Jika Anda menghapus aplikasi, seluruh data ikut terhapus dari perangkat.

Hak Anda

  • Akses data — data Anda berada di perangkat Anda sendiri.
  • Hapus data — hapus aplikasi atau gunakan tombol "Reset data" di Halaman Orang Tua.

Perubahan Kebijakan

Perubahan kebijakan akan diumumkan melalui pembaruan aplikasi. Halaman ini akan selalu menampilkan versi terbaru.
